# Codex Account Switcher 1.8.4

Version 1.8.4 keeps saved Codex accounts alive longer by refreshing aging OAuth tokens automatically, tells you when a refresh finally fails, and can alert you before saved reset credits expire.

## Automatic token refresh

- Tokens older than 3 days are refreshed proactively, before an account goes stale.
- If a usage request still comes back with a 400/401 response, the app performs one automatic retry with a freshly refreshed token.
- Updated tokens are written back to the account auth file atomically and mirrored into the active `~/.codex/auth.json` when the active account refreshes, so you rarely need to run `codex-auth login` again.
- If the automatic refresh finally fails, a notification tells you which account died and that it needs to be re-logged in with `codex-auth login` (per-account 6-hour cooldown).

## Reset credit expiry alerts

- A new "Credit expiry" automation toggle (on by default) alerts you 3 days before saved reset credits expire, based on the exact reset timestamps.
- Alerts are deduplicated per credit inventory, so a refreshed snapshot does not notify twice.
- Toggle it off any time in Settings under Automation.

## Maintenance

- Infrastructure coverage now includes token refresh requests, response parsing, error mapping, age policy, auth date parsing, and atomic token write-back, bringing the automated suite to 63 assertions.

The release is ad-hoc signed and includes a SHA-256 checksum. It is not Apple-notarized, so macOS may show the standard warning for independently distributed software.
